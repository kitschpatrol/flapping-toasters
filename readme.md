## Overview

This is a web port of [Flapping Toasters](https://frontiernerds.com/projects/flapping-toasters), a 2011 Kinect installation that let participants embody the flying toasters of After Dark screen saver fame:

- **Flap your arms** at a steady cadence to keep your toaster aloft
- **Clap** to pop toast
- **Tilt both arms** to barrel roll

[Play in your browser](https://frontiernerds.com/flapping-toasters) with a webcam. Up to six people at once can participate.

The source code for the 2011 openFrameworks + Kinect + OpenNI implementation lives in [`archive/`](archive/).
